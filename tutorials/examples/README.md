# Example Tutorials

One step-by-step tutorial per runnable example in [`../../examples/`](../../examples/). Same number, same name: `examples/07-sell-all.ts` is explained by `tutorials/examples/07-sell-all.md`.

Each tutorial walks through the example's actual code, shows how to run it (`npm run example <NN>`), what output to expect, and where to go next. The 44 numbered tutorials in [`../`](../) cover broader integration topics (bots, dashboards, MCP, x402); these stay focused on one SDK capability each.
